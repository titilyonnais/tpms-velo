# Application Web Bluetooth

Ce dossier contiendra la page web qui se connecte au boîtier par Web Bluetooth (Chrome sur Android). Elle servira à :
- régler les seuils d'alerte et la circonférence de roue ;
- consulter l'historique des pressions ;
- détecter les fuites lentes.

Elle sera d'abord mise au point dans le simulateur (module 3).
